農家のみなさんへ：いつもの診療のついでに、少しだけご協力ください

子牛の健康を、同じものさしで測って、一緒に良くしていく取り組みです。お願いすることは多くありません。

1

ついでに採ります

診療や、移動のために牛を捕まえたときに、ついでに血液・便・鼻のスワブなどを少しずつ採ります。採材のために捕まえる必要はありません。

2

結果は数字で返ってきます

農場の子牛の弱いところが見えるまとめ（子牛健康プロファイル）を、獣医師からお渡しします。

3

結果から、農場を良くする

結果の数字をもとに農場の改善に取り組めます。改善の効果も測り直せます。参加は無料です。

参加するとき

はじめに4つ。どれも、あとからでも大丈夫です

同意書に署名

くわしく測る農場（Deep）だけ。2枚に署名するだけで、書類を出す手続きはありません（下の「記録のこと」）

いくつか質問に答える

飼料、子牛の飼い方、牛の入れ替え、ワクチンなど。分からないところは「分からない」で大丈夫。獣医師が代わりに入力することもできます

牛舎にカードを貼る

牛舎の区画ごとに、QRの付いたカードを貼らせていただきます。貼る場所は相談して決めます

容器の置き場所

採材用の容器を置かせていただきます。置き場所は獣医師と相談して決めます

くわしく測る農場（Deep）は、去年1年の月ごとの分娩頭数（キャトルセンターは導入頭数）も、だいたいで教えてください。採材の季節を決めるのに使います。

頼まれたときだけ

農場に置くカード（印刷できます）

初乳カード

手で初乳を与える農場だけ

手で初乳を与えたときだけ。与えるのを優先して、手が空いたら少しだけ。
  1. 初乳キットの袋に、与えた初乳を少しだけ入れる
  2. 袋に子牛の耳標と日付を書く
  3. 農場の冷凍庫へ。次の診療で獣医師が受け取る
  4. 溶けてしまっても捨てずに凍らせて、獣医師に「溶けた」と伝える
飼料カード

頼まれたときだけ（獣医師が集めてもよい）

その日に与える飼料を、目安量のカードを見て袋に入れる。
  1. 数か所から袋に入れる
  2. 湿った飼料は薄く平らにして冷凍庫へ。乾いた飼料は口を閉じて常温で
  3. たまったら獣医師が送ります
  4. 代わりに送るときは、キットの事業の送り状に送り主だけ書いて貼り、火〜木曜日に出す（送料はいりません）
「動かさないでください」カード

測定器を置く農場だけ

空気を測っています。動かさないでください。
  1. 牛舎の柱に、小さな測定器をかごに入れて留めています
  2. 置くのは3〜7日。獣医師が次の診療で外します
  3. 高圧洗浄・消毒のときは、ビニールをかぶせる
  4. 落ちていた・動いていたら、そのまま獣医師に知らせる
複数回採便カード

2028年度だけ・頼まれた5農場だけ

この子牛が便をしたところを見たら、2日のうちに4回まで。待たなくてよい。
  1. 床についていない上の部分を、容器の線まで入れる
  2. 容器に日付と時刻を書く
  3. 農場の冷凍庫へ。次の診療で獣医師が受け取る
  4. 4回そろわなくても大丈夫

弱いところを、獣医師と一緒に良くする

見本です（数字は架空）。色の短い棒が、まず見るところ。

  1. まとめが届く子牛健康プロファイル。農場の子牛の状態が数字で見える
  2. 獣医師と見るどこが弱いか、何から直せそうかを一緒に考える
  3. 直してみる飼い方・環境など、農場でできることから
  4. また測る直したところを測り直して、良くなったか確かめる

記録のこと

子牛の成績は、聞き取りではなく記録から（くわしく測る農場）

使わせていただく記録

  • 牛の個体識別の届出の記録（出生・死亡・転出の日付）
  • 家畜共済（NOSAI）の記録（子牛の診療・死廃事故）。共済に入っていなければ使いません

取り寄せるのは事業の側（大学）です。農家さんの手続きは、同意書2枚への署名だけです。

大切にすること

  • 使うのは参加している農場の子牛の分だけ
  • 農場名・お名前は出さず、まとめた数字として示す
  • この事業以外には使わない
  • いつでも取りやめられる。取りやめても採材などは続けられる
  • 同意しなくても参加できます（その場合、この記録を使う計算から外すだけ）

実証協力農場（Broad）は、同意は任意です。
