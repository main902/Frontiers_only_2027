検体と結果の流れ

モノは4つの道を通り、結果は1か所（アプリ）に集まる

左から右へ。色のついた丸は、だれの手で動くか（青＝現場の獣医師・Coordinator、緑＝大学、灰＝外の施設）。

送り状はすべて事業で用意します。貼って出すだけで、現場で送料を払うことはありません。

血液・初乳・便
診療で採る→診療所で遠心・分注・凍結（−20℃）→Coordinatorの箱で月1回→大阪：受け取り・仕分け、Brix・TP・便の前処理→血清1本はNOSAIへ（血液生化学）

便の核酸は大阪で抽出して宮崎へ（qPCR）。残りは大阪で−80℃保存。

鼻咽頭スワブ・水槽スワブ
診療で採る→診療所で冷凍→事業の送り状で宮崎へ（まとめて）→宮崎：抽出・qPCR

発症牛の鼻咽頭スワブは、次の宮崎便に入れる。保存用はSeasonの終わりに大阪へ。

飼料
農場で袋に採る→農場から直送（事業の送り状）→全酪連：飼料分析
環境（センサー）
牛舎に3〜7日置く→データを同期→次の農場へ直送→年度末に大阪へ返す
結果の流れ
大阪・宮崎NOSAI・全酪連→アプリに集まる→農場ごとの子牛健康プロファイル→獣医師から農家さんへ

子牛の成績（出生・死亡・治療・出荷）は、農家さんの同意のうえで牛個体識別と家畜共済の記録からアプリに取り込む予定です（くわしくは「計画フロー」の相談ページ）。

Broadの農場

年50農場（目標）、全国からいつでも登録できる。登録した日から始められ、改善して測り直すまで、その農場のペースで進む。

病気の牛（呼吸器の初診・下痢）の採材は、DeepもBroadも季節に関係なく1年中できます。

1回の流れ

Deepの1季節と、Broadの1農場

Deep：1つのfarm-season
  1. 採材計画参加のとき、獣医師と大阪で作る
  2. キットが届く年度初めにCoordinatorから
  3. アプリで残りを見て採る何が・あといくつ残っているかを見て、診療のついでに。足りなくても待たない
  4. 遠心・分注・凍結採血から2時間以内の分離が目標
  5. 月1回送る大阪へは採血から30日以内に着くように
  6. プロファイル季節の結果をまとめて返す
Broad：1つの農場
  1. 登録するだけアプリで。その日から始められる
  2. 手元の資材で4項目基本情報・Zone動画・胸囲・水槽スワブ
  3. 最初のプロファイル分かること・分からないことを示す
  4. 何を詳しく調べるか検討担当とセンターの獣医師で（Add-on）
  5. 改善する飼い方・環境を農家さんと見直す
  6. 測り直す関係する項目だけ、30〜60日後に
6つの領域と、何を測るか

牛の段階（Stage）ごとに、決まったものを採る

M1分娩の8〜60日前の母牛
M2分娩後8〜60日の母牛
P0生後2〜7日
P230日齢〜離乳開始
P3離乳のころ（2028年度R&Dだけ）
P4離乳完了の15〜60日後

Stageはアプリが自動で決めます。1つのStageで目標5頭（最大8頭、最低なし）。

01

母牛の栄養・代謝

採る：M1・M2の血液、母牛の飼料

測る：NOSAI（血液生化学）、全酪連（飼料）

02

初乳・初期免疫

採る：P0の血清、初乳

測る：大阪（Brix・TP。IgGは2028年度）

03

子牛の栄養・発育

採る：P2・P4の血液、P4の健常便、子牛の飼料、胸囲

測る：NOSAI、大阪、全酪連

04

呼吸器（BRDC）

採る：健常子牛の鼻咽頭スワブ（30〜90日齢を優先）、発症牛の鼻咽頭スワブ

測る：宮崎（qPCR）

05

下痢・消化器

採る：下痢の便、比べるための健常便

測る：大阪（前処理・抽出）→ 宮崎（qPCR）

06

飼養環境

採る：環境センサー（3〜7日）、水槽スワブ、Zone（牛舎の区画）

測る：大阪（センサー）、宮崎（水槽スワブ）

灰色の2つ（呼吸器・飼養環境）は前の事業で確立した領域。Broadでは、これらを必要な農場だけ追加で調べます（Add-on）。

だれが何をするか

それぞれの役割

Deepの獣医師 →
  • 診療のついでに採る・記録する
  • 遠心・分注・凍結
  • 病気の牛の鼻咽頭スワブ・下痢便
Broadの獣医師 →
  • 農場を登録し、手元の資材で4項目
  • 何を詳しく調べるか検討
  • 農家さんと改善し、測り直す
農家さん →
  • キットを置く場所を貸す
  • 同意書2枚にサインする
  • プロファイルを受け取る
Coordinator（地域のまとめ役） →
  • キットを受け取り、獣医師に渡す
  • 冷凍の検体を月1回まとめて大阪へ
  • 在庫を見て補充をたのむ
大阪（中央拠点） →
  • とりまとめ・採材計画・キット
  • 受け取り・仕分け・中央の測定
  • プロファイル作成、−80℃保存
宮崎大学 →
  • 鼻咽頭スワブ・水槽スワブの受け取り
  • 核酸の抽出とqPCR（呼吸器・下痢）
  • 保存用を季節の終わりに大阪へ
明治大学・委員会
  • 明治大学：データの確認と解析、経済評価
  • 推進委員会：年1回（2029年度は評価委員会も）
外の施設
  • NOSAI：血液生化学
  • 全酪連：飼料の分析

立場ごとのくわしいページは、この全体図に続けて同じ作りで作ります。

みんなに共通の決まり

6つだけ

  1. 採材のためだけに行かない頭数が足りなくても待たない・追加で行かない・次の季節で埋めない
  2. 数は「上限」必ず採る数ではない。予算を使い切るために増やさない
  3. 問題のある検体も捨てない送って、アプリで印（flag）を付ける
  4. 溶かすのは1回だけ凍らせた検体は、測るときまで溶かさない
  5. 温度管理と追跡ができる方法で送る大阪へは採血から30日以内に着くように
  6. 分からないことは推測で埋めない「分からない」のまま記録してよい。記録はアプリへ
ことば表
このページで使うことば（開く）
Deep（重点調査農場）
全国50農場。3年間登録し、標準（ものさし）を作るためにくわしく測る
Broad（実証協力農場）
年50農場（目標）。標準を使って改善し、測り直す
farm-season
農場×季節。Deepの1農場で1季節くわしく測ると1 farm-season。3年で100
Stage（段階）
牛の段階。M1・M2（母牛）、P0・P2・P3・P4（子牛）。アプリが自動で決める
Routine／Event
Routine＝季節の中で段階ごとに採る。Event＝病気の牛（呼吸器の初診・下痢）をいつでも採る
蓄積式（診療・農場フロー蓄積式）
1回で全部採ろうとせず、通常診療の中で検体を少しずつ集めるやり方。公開HPのSOPでは「K式」
鼻咽頭スワブ（NPS）
鼻の奥（咽頭壁）の拭い液。呼吸器の病原体を調べる
水槽スワブ（WTS）
共用の水槽の拭い液。環境中の呼吸器病原体を調べる
胸囲（HGR）
子牛の胸囲。発育の目安
Zone
牛舎の区画。区画ごとにQRカードを貼り、動画を撮る
Coordinator
地域のまとめ役（BRDC Frontiersの会員）。キットと検体の受け渡し
センターの獣医師
大阪の獣医師。Broadで、何を詳しく調べるかを担当の獣医師と一緒に検討する
Add-on
Broadで、必要な農場だけ追加で詳しく調べる項目
子牛健康プロファイル
農場ごとの結果のまとめ。獣医師から農家さんに返す
flag（印）
問題のある検体・記録に付ける印。捨てずに残す
SDCA／PDCA
SDCA＝標準を作り守る輪（Deep）。PDCA＝標準で改善する輪（Broad）
3M
ムリ・ムダ・ムラ。これを生まないように、アプリと蓄積式で支える
